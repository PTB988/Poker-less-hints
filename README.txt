HOME CASH POKER TRAINER — ADAPTIVE OFFLINE VERSION

Upload the contents of this folder to the root of your GitHub Pages repository, replacing index.html and sw.js and keeping manifest.webmanifest. Commit changes, then wait for GitHub Pages to redeploy. The service worker cache version is bumped to v3.

Features: rule-based varied scenario templates, per-skill accuracy tracking, locally saved history, adaptive category weighting based on errors and under-tested skills, no API key or subscription. Data stays in the browser localStorage on that device. Scenarios and coaching are heuristic—not solver-verified.
